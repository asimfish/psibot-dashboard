## 本次方法与 baseline 的区别

| 模块 | 本次 ours 配置 |
| --- | --- |
| 执行器训练 | 从官方2B基座初始化；前10k读取全部历史KF，后20k使用DAG；一个30k学习率计划，完整续接优化器和scheduler |
| 记忆 token | 首帧独立1个融合token，每个被读取的前序子任务独立1个融合token；不是M(1)的首帧8-token方案 |
| 关键帧选择 | Gen2.1-311 State私有128维特征；原BIC聚类，λ=100、K≤4、每簇至少3个候选帧 |
| 完成判断 | 外部Gen2.1-311 Completion头，当前子任务S128历史；原生执行器classifier禁用，训练仅动作loss |
| 两头共享 | Completion与State共享底层，四份阶段权重保持同一训练依赖链 |
| 子任务Planner | 三任务v13第三人称LoRA，输出实际当前子任务文本 |
| DAG Planner | 独立三任务v13 LoRA，根据真实历史和当前实际指令预测记忆依赖 |
| 额外历史读取 | `temporal_predecessor_keyframes: latest`，补充紧邻上一子任务最新KF；这是独立读帧规则，不是新增DAG边 |
| 子任务切换 | 清空阶段短期记忆和旧动作余量，保留首帧与已归档历史KF |

当前完成阈值为 **0.975、累计两次阳性**，没有额外N30；分类器开始需要3个真实观测，前2帧为窗口warmup。它是尚未通过SafeLab闭环效果校准的初始配置，不是RMBench其他任务的最佳阈值。

训练DAG使用零基 `[] / [] / [0]`，表示第三个子任务依赖第一个。首帧独立、不占子任务ID。**在线读取以DAG Planner预测为准，不与训练DAG比对。** Gen2.1-311接受实际Planner文本，不查询训练指令白名单；没有预设最后子任务编号或末阶段跳过规则。

Planner输出 `Done/Finished/End the task` 时，在已有可执行指令的情况下保留当前指令和记忆继续执行，不直接判成功。环境报告成功或结束时，在任何模型调用前退出。由合作者的环境成功检查决定任务是否成功。

## 输入输出与控制

输入为原始第三人称RGB `uint8[H,W,3]` 和13维实测关节角（rad），不能提前归一化或改成其他相机。输出 `actions_rad[30,13]` 是**绝对关节目标角**，不是增量、速度或120Hz中间轨迹。

本轮图像15Hz，动作标签沿用三任务 `interval_end`，每个目标对应图像区间末尾。30个预测目标约覆盖2秒，120Hz控制下每个目标间隔约8个控制步；控制器、物理子步及插值由合作者验证。每个真实观测都要调用policy，默认每30个观测生成新chunk；子任务切换可提前丢弃旧chunk并立即重算。完整关节顺序、reset和实际调用方式见START_HERE。

冻结ours接口的图片参数历史名称仍为 `chest_rgb`，本轮实际配置与输入均为第三人称。请按START_HERE用位置参数调用 `policy.step(third_person_rgb, measured_qpos, ...)`，不要因为参数旧名称改用chest图像。
