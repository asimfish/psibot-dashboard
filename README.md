# psibot-dashboard data branch
Machine-generated GPU snapshots for https://asimfish.github.io/psibot-dashboard/ (§S). Updated every 10 min by the collector on the maintainer's Mac.
- `gpu_snapshot.json`: same schema as the live feed (`machines.<key>.gpus[]` with mem/tot/util/et/cmd/ev), plus `snapshot_ts` (ISO, UTC+8) and `snapshot_epoch`.
