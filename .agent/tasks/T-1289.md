# T-1289 — Dataset user-review page, V2

Status: review

## Outcome

Publish a browsable review view of the four frozen datasets, 100 episodes each.
This page does not grant formal acceptance. Human review, OOD scope, frame-rate
deviations, and outstanding collision or image-pipeline checks remain explicit.

## Evidence boundaries

The public JSON is an explicit allowlist of per-episode review metrics. It does
not include raw trajectories, assets, storage locations, or internal provenance.
The frame pairs and representative H.264 videos are CPU-generated derivatives;
the source data remain unchanged. Each dataset has 100 thumbnail pairs, one
100-episode montage, and six representative videos.

Peak-force definitions differ: FR3 uses the sum of three hand-body net-force
vector norms at every physics step, with a 25 N limit. Press uses the maximum
sensor-link × button contact pair norm at every physics step, with the user's
50 N limit. Press RGB and stored states are 7.5 Hz, the other datasets 30 Hz;
physics and force are 120 Hz. Spatial checks use the actual object at termination.

## Verification

- Browser: 400 rows, four datasets, 24 videos, dataset/episode filtering, image
  dialog, image load, H.264 metadata load, desktop and mobile layout.
- Content: exact 100 rows per dataset, measured per-episode force and object
  endpoints, correct maximum-force and maximum-distance video selections.
- Publication: all owned text and media metadata scanned for internal paths,
  identities, storage keys, private addresses, and credential markers.
- Media: no audio, H.264, at most 1280 × 720, each clip at most 5 MB.
- Size: owned additions below 300 MB; every file below 50 MB.
